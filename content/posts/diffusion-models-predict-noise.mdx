디퓨전 모델이 이미지를 만드는 과정을 보면 신경망이 노이즈 속에서 그림을 그려 내는 것처럼 보인다. 그런데 [DDPM](https://arxiv.org/abs/2006.11239)(Ho, Jain, Abbeel, 2020) 방식으로 학습하는 신경망이 받는 문제는 그림을 그리는 일이 아니다. 노이즈가 섞인 이미지를 보고, 거기에 섞인 노이즈를 맞히는 일이다.

식 번호와 절 번호는 따로 적지 않으면 DDPM 논문을 따른다.

## 망가뜨리는 과정은 학습하지 않는다

디퓨전 모델은 2015년 [Sohl-Dickstein 등](https://arxiv.org/abs/1503.03585)이 제안한 생성 모델에서 출발한다. 데이터의 구조를 반복적인 정방향 확산(forward diffusion)으로 천천히 무너뜨리고, 구조를 되살리는 역방향 과정을 학습해 생성에 쓴다.

DDPM의 정방향 과정은 단계마다 이전 값을 조금 줄이고 가우시안 노이즈를 조금 더한다. 이미지 `x_0`에서 시작해 `x_1`, `x_2`를 거쳐 `x_T`로 갈수록 노이즈가 늘어난다. 논문은 한 단계를 분포로 정의하는데(식 2), 그 분포에서 표본을 뽑는 꼴로 쓰면 아래와 같다. `ε`는 표준정규분포에서 뽑은 노이즈다.

```text
x_t = sqrt(1 - β_t) * x_{t-1} + sqrt(β_t) * ε
```

`β_t`는 단계마다 섞는 노이즈의 분산이다. 논문은 `T = 1000`으로 두고 `β_t`를 `0.0001`에서 `0.02`까지 선형으로 키웠고(4절), 이미지의 픽셀 값은 `[-1, 1]` 범위로 맞춰 넣었다(3.3절). `β_t`를 상수로 고정했기 때문에 정방향 과정에는 학습할 매개변수가 없다(3.1절).

이 과정은 `t`번 반복하지 않고 한 번에 계산할 수 있다. `α_t = 1 - β_t`로 두고, `ᾱ_t`를 `α_1`부터 `α_t`까지의 곱이라고 하면 `x_0`에서 `x_t`를 바로 뽑을 수 있다. 아래는 식 4의 분포에서 표본을 뽑는 꼴이다.

```text
x_t = sqrt(ᾱ_t) * x_0 + sqrt(1 - ᾱ_t) * ε
```

아래는 이 두 식을 NumPy로 옮긴 예시다.

```python
import numpy as np

T = 1000
betas = np.linspace(1e-4, 0.02, T)  # β_1 … β_T
alphas = 1.0 - betas  # α_t
alpha_bars = np.cumprod(alphas)  # ᾱ_t = α_1 × … × α_t


def add_noise(x0, t, rng):
    """x_0에서 x_t를 한 번에 만든다. t는 1부터 T까지다."""
    eps = rng.standard_normal(x0.shape)
    a_bar = alpha_bars[t - 1]
    xt = np.sqrt(a_bar) * x0 + np.sqrt(1 - a_bar) * eps
    return xt, eps
```

`x_t`는 원본에 `sqrt(ᾱ_t)`를 곱한 값과 노이즈에 `sqrt(1 - ᾱ_t)`를 곱한 값의 합이다. 논문의 `β_t` 설정으로 두 계수를 계산하면 다음과 같다. 측정값이 아니라 위 코드로 직접 계산한 값이다.

| t    | 원본 계수 `sqrt(ᾱ_t)` | 노이즈 계수 `sqrt(1 - ᾱ_t)` |
| ---- | --------------------- | --------------------------- |
| 1    | 0.9999                | 0.0100                      |
| 100  | 0.9471                | 0.3209                      |
| 250  | 0.7239                | 0.6899                      |
| 500  | 0.2803                | 0.9599                      |
| 750  | 0.0579                | 0.9983                      |
| 1000 | 0.0064                | 1.0000                      |

마지막 단계에서는 원본 계수가 0.0064까지 줄어 거의 노이즈만 남는다. 그래서 생성은 표준정규분포에서 뽑은 노이즈를 `x_T`로 두고 시작한다.

## 신경망은 섞인 노이즈를 맞힌다

생성은 이 과정을 거꾸로 따라간다. `x_t`에서 `x_{t-1}`로 가는 역방향 한 단계를 가우시안 분포로 두고(식 1), 그 평균을 신경망으로 근사한다. 분산은 `σ_t² = β_t` 같은 상수로 고정했다(3.2절).

평균을 신경망이 직접 내놓게 할 수도 있지만, DDPM은 신경망 `ε_θ(x_t, t)`가 `x_t`에 섞인 노이즈 `ε`를 예측하게 하고 평균은 그 예측값으로 계산한다(식 11).

```text
μ_θ(x_t, t) = (x_t - β_t / sqrt(1 - ᾱ_t) * ε_θ(x_t, t)) / sqrt(α_t)
```

`x_t`에서 예측한 노이즈를 전부 빼지 않고 이번 단계에 해당하는 일부만 뺀 뒤, 정방향 한 단계에서 줄인 크기(`sqrt(α_t)`)를 되돌리는 식이다.

DDPM의 원래 학습 목표는 변분 하한(variational bound)이다. 데이터가 나올 확률(로그 가능도)을 직접 계산하기 어려워 그 하한을 대신 키우는 목표로, 단계마다 항이 하나씩 생긴다(식 3, 5). 노이즈 예측으로 바꾸면 단계별 항은 실제로 섞은 노이즈와 예측한 노이즈의 제곱 오차에 단계별 가중치를 곱한 꼴이 된다(식 12). 논문은 이 가중치를 뺀 아래 식으로 학습했다(식 14).

```text
L_simple = E[ || ε - ε_θ(sqrt(ᾱ_t) * x_0 + sqrt(1 - ᾱ_t) * ε, t) ||² ]
```

학습 한 번은 알고리즘 1을 따른다. 데이터에서 이미지를 하나 고르고, `t`를 1부터 `T` 사이에서 무작위로 뽑고, 노이즈를 섞은 `x_t`를 신경망에 넣어 그 노이즈를 맞히게 한다. 아래는 이미지 한 장 기준으로 단순화한 예시다. `model`은 `x_t`와 `t`를 받아 `x_t`와 같은 모양의 배열을 돌려주는 신경망을 나타낸다.

```python
def training_loss(model, x0, rng):
    t = rng.integers(1, T + 1)  # t ~ Uniform({1, …, T})
    xt, eps = add_noise(x0, t, rng)  # 식 4로 x_t를 바로 만든다
    eps_pred = model(xt, t)  # ε_θ(x_t, t)
    return np.sum((eps - eps_pred) ** 2)
```

실제 학습은 이 손실을 배치로 계산해 경사 하강법으로 신경망의 가중치를 갱신한다. 식 4 덕분에 `t`가 얼마든 `x_t`를 한 번의 계산으로 만들 수 있어서, 학습할 때는 1,000단계를 차례로 밟지 않는다. `t`마다 신경망을 따로 두지도 않는다. 논문은 U-Net 하나의 매개변수를 모든 단계가 공유하게 하고, `t`는 사인·코사인 값으로 이뤄진 벡터로 바꿔(Transformer의 위치 임베딩과 같은 방식) 넣었다(4절).

노이즈 예측은 평균에 대한 학습 목표를 전개하다 나온 매개변수화이고(식 10, 11), 논문은 이 선택이 나은지를 실험으로 확인했다. CIFAR10에서 비교했을 때 평균을 직접 예측하는 방식은 원래의 변분 하한으로 학습할 때만 잘 동작했고, 가중치 없는 제곱 오차로 학습하면 불안정하고 샘플 품질도 나빴다. 분산을 고정하고 변분 하한으로 학습하면 두 방식이 비슷했지만, `L_simple`로 학습하면 노이즈 예측 쪽이 훨씬 좋았다(4.2절, 표 2). 원본 `x_0`를 바로 예측하는 방식은 초기 실험에서 샘플 품질이 더 나빴다고 적었다(3.2절).

`L_simple`처럼 단계별 가중치를 빼면 논문의 설정에서는 노이즈가 아주 적은 작은 `t` 항의 비중이 줄고, 신경망은 노이즈가 많은 큰 `t`에서의 더 어려운 노이즈 제거에 집중한다(3.4절).

## 생성은 1,000번의 순차 실행이다

생성은 알고리즘 2를 따른다. 표준정규분포에서 뽑은 `x_T`에서 시작해, 단계마다 신경망이 예측한 노이즈로 평균을 계산하고 새 노이즈 `z`를 조금 더해 `x_{t-1}`을 만든다. 마지막 단계에서는 노이즈를 더하지 않는다. 앞의 예시 코드에 이어 쓰면 다음과 같다.

```python
def sample(model, shape, rng):
    x = rng.standard_normal(shape)  # x_T ~ N(0, I)
    for t in range(T, 0, -1):
        beta, alpha, a_bar = betas[t - 1], alphas[t - 1], alpha_bars[t - 1]
        z = rng.standard_normal(shape) if t > 1 else 0.0
        eps_pred = model(x, t)
        x = (x - beta / np.sqrt(1 - a_bar) * eps_pred) / np.sqrt(alpha)
        x = x + np.sqrt(beta) * z  # σ_t = sqrt(β_t)
    return x  # x_0
```

학습과 달리 DDPM의 생성은 단계를 건너뛸 수 없다. `x_{t-1}`을 만들려면 `x_t`가 있어야 하므로, 이미지 한 장을 만드는 데 신경망을 1,000번 차례로 실행한다. [DDIM 논문](https://arxiv.org/abs/2010.02502)은 Nvidia 2080 Ti GPU에서 DDPM으로 32×32 이미지 5만 장을 만드는 데 약 20시간이 걸리고, 신경망을 한 번만 실행해 이미지를 만드는 GAN으로는 1분이 안 걸린다고 비교했다. DDIM은 학습은 DDPM과 같게 두고 1,000단계 중 일부만 골라 밟는 생성 과정을 써서, 같은 모델로 실제 걸리는 시간 기준 10배에서 50배 빠르게 샘플을 만든다고 보고했다(DDIM 논문 초록, 4.2절).

## 픽셀 대신 압축한 공간에서 돌린다

픽셀 공간에서 직접 학습하는 디퓨전 모델은 비싸다. [Latent Diffusion 논문](https://arxiv.org/abs/2112.10752)(Rombach 등, 2021)은 강력한 디퓨전 모델을 학습하는 데 GPU 수백 일이 드는 경우가 많고, 순차적으로 여러 번 평가해야 해서 추론도 비싸다고 지적한다. 그래서 미리 학습한 오토인코더로 이미지를 작은 잠재 표현(latent)으로 압축하고, 디퓨전은 그 공간에서 돌린다. 학습 목표는 그대로 노이즈 예측이고, 입력만 픽셀 대신 잠재 표현이 된다. 생성이 끝난 잠재 표현은 오토인코더의 디코더가 이미지로 되돌린다. 텍스트 같은 조건은 별도 인코더로 바꾼 뒤 cross-attention 층으로 U-Net에 넣는다.

[Stable Diffusion v1](https://github.com/CompVis/stable-diffusion#stable-diffusion-v1)이 이 구조다. 가로세로를 8분의 1로 줄이는 오토인코더 위에서 U-Net이 디퓨전을 돌리고, CLIP ViT-L/14 텍스트 인코더의 출력을 조건으로 받는다. 512×512 이미지라면 디퓨전은 가로세로 64의 잠재 표현에서 돌아간다.
