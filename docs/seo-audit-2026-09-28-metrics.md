홈 모바일은 성능 55~96, LCP 1.6~13.2초로 편차가 컸다. 세 표본의 성능 중앙값은 55지만, 이를 실제 사용자 평균으로 해석하면 안 된다. RABBIT 상세는 두 표본 모두 성능 34~35로 낮고 LCP는 27.2~36.8초였다. 네트워크·CPU 시뮬레이션과 페이지 렌더링 타이밍의 영향을 받으므로 사이트 변경 후 같은 조건으로 비교한다.

데스크톱 검사 준비 과정에서 preset 인자가 JS API에 적용되지 않은 추가 모바일 표본 2개를 발견했다. 이 두 결과는 기기 표와 집계에서 제외하고 별도 `*-mobile-extra.report.*` 원본으로 보관했다. 데스크톱 12개는 공식 desktop config를 명시해 다시 측정했고 모두 `formFactor=desktop`을 확인했다.

## 재현

```bash
npm run build
npm run lint
npm run start -- --hostname 127.0.0.1 --port 3217
```

Lighthouse는 npm 임시 도구 폴더에 설치했고, 소스 의존성이나 lockfile에 추가하지 않았다. `lighthouse.mjs`의 초기 mobile 측정과 `lighthouse-verify.mjs`의 명시적 desktop 설정을 사용했다. API 인증 토큰·refresh token·환경변수 값은 증거 묶음에 포함하지 않는다.
