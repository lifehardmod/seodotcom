# SEO·성능 수정 — 2026-09-29

2026-09-28 점검에서 발견한 문제를 실제 소스에 반영했다. 12개 화면의 정적 생성과 기존 피드백 API 구조를 유지한다. 소스는 로컬 수정 상태이며 커밋·push·운영 코드 배포는 하지 않았다. Vercel의 두 도메인 리다이렉트 설정은 실제 적용했다.

이 문서는 첫 수정 단계의 기록이다. 이후 페이지별 폰트·지연 로딩·이미지 개선 및 최종 측정은 [모바일 성능 추가 최적화](./mobile-performance-2026-09-29.md)에 기록했다.

## 검색 정보와 콘텐츠

- `src/lib/seo.ts`에 12개 경로의 제목, 설명, canonical, OG URL, 검색 공개 여부를 정의했다. 모든 페이지가 자신의 최종 `https://www.seojuwon.work` URL을 대표 주소로 출력한다.
- 공개 경로 `/`, `/programming`, `/programming/rabbit`, `/programming/mimo`, `/resume` 5개를 사이트맵에 넣었다. 의미 없는 빌드 시각 `lastmod`, `changefreq`, `priority`를 제거했다. robots의 사이트맵 URL도 www로 맞췄다.
- 기존 메뉴에서 숨긴 7개 경로는 `noindex, follow`로 설정했다. 블로그·두더지 상세·ClassOn·UX 목록 및 상세 3개다. 페이지 접근은 유지한다. 공개하려면 내용을 확인하고 내부 링크를 연결한 뒤 `SEO_PAGES`의 `index`를 바꾸면 된다. 실수로 준비 중인 페이지를 모두 검색에 공개하지 않도록 한 정책이다.
- Google 소유권 확인 메타 태그는 보존했다. 9월 28일 성공한 사이트맵 주소는 그대로 유지한다. **코드 배포 후에 Google이 갱신된 5개 URL을 읽을 수 있다.** 검색 색인 완료나 Google 선택 canonical은 이 수정만으로 확인되지 않는다.
- 실제 400×500 프로필 이미지에 맞는 OG 크기와 Twitter summary 카드를 사용한다. 홈·이력서의 Person/ProfilePage, 홈의 WebSite, 하위 페이지의 BreadcrumbList JSON-LD를 추가했다.
- 개발·UX 목록의 문장을 하나의 H1로 정리하고, 프로젝트 개요·설명 제목의 H2/H3 순서를 바로잡았다. JavaScript를 끄더라도 홈 제목과 캐러셀 첫 이미지를 볼 수 있다.
- A7M3에 제목·소개·설명형 alt, Assembly·두더지에 실제 확인 가능한 소개를 추가했다. 작성되지 않은 성과를 만들어 채우지는 않았다.
- RABBIT의 상위 섹션은 서버에서 모든 본문을 출력하는 네이티브 details로 바꿨다. 다른 슬라이드·탭의 설명도 최초 HTML에 유지한다.
- 공용 카드의 `id === 3` 특례를 제거했다. A7M3는 자신의 상세 페이지로, 두더지는 데이터에 명시된 외부 게임으로 이동한다.
- 공개 방문 시 404인 RABBIT/MIMO 저장소 링크는 접근 가능한 GitHub 프로필 링크로 바꾸고, 버튼 문구도 `서주원의 GitHub`로 명시했다. 저장소의 비공개·이동·삭제 여부는 단정하지 않는다.

폰트는 실제 소스의 글자와 HTML 기호를 포함한 서브셋으로 만들고 `next/font/local`로 로드한다. 원본 글리프는 unicode-range를 제한한 fallback으로 남겨 새 문구·사용자 입력의 누락 글자를 지원한다. 전체 HTML을 검사해 현재 출력 글자가 서브셋에서 누락되지 않았고, 초기 브라우저 요청에서 대용량 원본 폰트를 다시 받지 않는 것을 확인했다. `font-display: optional`이므로 느린 연결에서는 해당 방문 동안 시스템 폰트로 표시될 수 있다.

모바일·모션 감소 설정·데이터 절약 연결은 포스터를 먼저 보여준다. 방문자가 원하면 영상을 재생할 수 있다. 데스크톱 자동 재생은 화면에 보일 때만 수행하며 일시정지 버튼을 제공한다. 영상 표시 영역의 높이를 예약하고 포스터/LCP 이미지를 우선 요청한다.

3D 코인은 버튼을 누를 때만 Three.js와 Canvas를 로드한다. 원격 HDR 파일과 후처리를 제거하고 로컬 조명으로 대체했다. 화면 밖·숨긴 탭·모션 감소 설정에서는 지속 프레임을 멈추며, 닫을 때 Canvas와 텍스처를 정리한다. WebGL을 사용할 수 없는 환경에는 안내를 출력한다. 클릭 전에는 3D 코드·Canvas·HDR 다운로드가 없다.

반응형 화면은 가벼운 정적 미리보기를 사용하고 확대하면 원본 애니메이션을 볼 수 있다. 코드 예제는 빌드/서버에서 JSX 문법을 강조하며 전체 문법 하이라이터를 브라우저에 보내지 않는다. 긴 디자인 시스템 예시는 `content-visibility`로 화면 밖 레이아웃을 미룬다.

## 접근성과 기능

- 최대 배율 제한을 제거했다. 코드 블록·탭·설명·데모 버튼의 대비, 이름 없는 아이콘 버튼, 캐러셀 터치 영역, 제목 단계를 수정했다.
- 홈 타이핑 영역의 높이를 예약하고 모션 감소 설정을 반영했다.
- 첫 방문에 본문을 가리는 피드백 팝업 자동 표시를 제거했다. 버튼으로 열 수 있고, 입력 라벨·전송 중 상태·실패 안내를 제공한다. 실패 시 내용을 보존하며 성공 응답을 확인한 후 닫는다.
- 숨겨진 NFT 데모를 정적 HTML에 포함하면서 드러난 날짜/로케일 hydration 오류를 수정했다. 예시 날짜는 고정하고 카운트다운은 hydration 후 시작한다.
- 기존 RABBIT 디자인 시스템의 그라데이션 예시와 NFT 브랜드 글자색은 포트폴리오에서 설명하는 실제 디자인 자료이므로 유지했다. 디자인 훅의 `gradient-text` 경고는 이 문맥에서 의도된 예시이며, 경고를 숨기는 설정은 추가하지 않았다.

## 재현과 검증

```sh
nvm use
pnpm install --frozen-lockfile
npm run build
npm run lint
npm run start -- --port 3000
# 다른 터미널
npm run test:seo -- http://127.0.0.1:3000
```

`scripts/check-seo.mjs`는 파일 시스템에서 페이지 경로를 찾고, 빌드된 실제 응답의 고유 메타데이터·canonical·OG·robots·H1·구조화 데이터·사이트맵·404·주요 링크를 검사한다. 12개 페이지와 사이트맵 5개 URL이 통과했다.

브라우저에서 12개 경로 × JavaScript 사용/미사용 24개 실행을 했고, 각각 390px·1440px 화면을 확인했다. 관측한 화면에서 런타임 오류, 실패한 리소스, 로딩 완료된 이미지의 깨짐, 문서 가로 넘침이 없었다. 3D 열기/닫기, 원본 애니메이션 확대, 섹션 열기, 영상 재생/정지, 모션 감소 설정도 통과했다. 모든 숨겨진 UI 조합의 접근성을 완전히 증명하는 검사는 아니다.

피드백 실패/성공 검증은 Playwright에서 `/api/feedback` 응답을 가로채 모의 응답으로 수행했다. 실제 Discord 메시지는 보내지 않았다.

콘텐츠나 원본 미디어가 바뀌면 다음 스크립트로 파일을 재생성한다. 생성 결과는 저장소에 포함하며 배포 시 Python/ffmpeg가 필요하지 않다.

```sh
python3 -m pip install 'fonttools[woff]'
python3 scripts/subset-fonts.py
# ffmpeg 설치 필요
node scripts/optimize-media.mjs
```
